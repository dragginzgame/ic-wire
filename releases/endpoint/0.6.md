# Endpoint 0.6 release contract

Endpoint 0.6 adopts Core 0.16's public Error, Limits, native codec and host schema
identity, selecting Runtime/macros/exact guard 0.19. Canonical Principal/Account
come from Types 0.18. Align direct imports, Timers and other execution adapters;
older runtime generations must not be mixed with this singleton. Platform still
owns exports and execution; no new executor is introduced.

[Core's contract](../core/0.16.md) owns the Account byte/schema cut. Present
subaccounts change from `01 + 32 bytes` to `01 20 + 32 bytes`; None remains `00`.
Regenerate Uint8Array clients, use fresh keys and requalify all four budgets.
Current macros retain `id` and exported-name defaults: schema/package changes
do not update those keys. Preserve original retry/hash bytes and resolve retained
operations and unframed stored data under consumer policy. No legacy reader,
parallel endpoint or automatic migration is provided.

Qualification selects published Platform/PocketIC 0.19 and Testkit 0.81. Require
observed typed canister errors in negative tests and cost samples; HTTP/client
failures cannot establish malformed-input refusal or rollback. No uncertain
operation is retried by these callers. Synchronous encoding traps still roll back
mutations; async state committed before an await remains committed.

[Paired supplier evidence](../../docs/evidence/account-platform-cut.md)
checks all 17 exports, both profiles and 356 case/profile pairs, including request/
reply bytes and complete physical executions. Keep final factory, installed and
registry-only proofs distinct from the earlier temporary managed-server bootstrap.
The complete release gate and Core supplier publication precede Endpoint release/
publication, followed by exact archive/source/registry verification.

Automatic contract-key generation is still
[isolated research](../../docs/evidence/contract-artifact.md). This
release preserves the production macro options, header layout and one codec.

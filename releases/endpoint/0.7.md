# Endpoint 0.7 release contract

Endpoint and `ic-wire-endpoint-macros` share one release group. Import attributes
through `ic_wire_endpoint::{query, update}` as before; application dependencies
need no direct proc-macro entry. Macro-only changes can now release independently
of Core's metadata derive. Publish macros before the Endpoint facade.

Align Core 0.17's public codec/schema/limits identities. Select Endpoint's
`typescript` feature for native Contract projections; it forwards Core's optional
metadata derive. The supplying Runtime/macros/guard remain 0.19.1, with compatible
Runtime range ^0.19.0, and canonical Types 0.18.1. Platform owns exports and execution.

This release changes package ownership and API selection, with no change to
generated contracts, frame bytes, IDs, admission, borrowing or sync/async rollback.
No retained-byte or method-key migration is needed from Endpoint 0.6/Core 0.16.
Earlier consumers still follow the [Core 0.16 Account cut](../core/0.16.md).

[Core's release contract](../core/0.17.md) owns dependency and metadata migration.
Qualification includes standalone host/Wasm schemas, default runtime isolation,
stable future identities, exact generated tokens, installed calls/limits/rollback
and total/code uncompressed Wasm. Fresh final gates and installed registry
consumers remain distinct from earlier implementation experiments.

# Core 0.17 release contract

Core's codec no longer selects `ic-wire-derive` by default. Runtime DTOs need
ordinary Serde implementations. Schema-generating consumers explicitly enable
`ic-wire/typescript` before deriving `ic_wire::Wire`; `platform-types` and
Endpoint's `typescript` feature already forward that selection. No second derive
feature or codec is introduced. Forwarding metadata to Wasm still selects its
host proc macro for shared declarations; JSON/schema implementations stay native.

Query/update generation moves from Core's derive into `ic-wire-endpoint-macros`,
released with Endpoint. The old `ic-wire-derive/endpoint` feature and direct
attributes are removed. Use `ic_wire_endpoint::{query, update}` and align
Endpoint 0.7 with Core 0.17. Endpoint's attribute options and generated contracts
remain unchanged. Publish derive then Core, followed by Endpoint macros then
Endpoint; qualification packages remain unpublished.

There is no protocol cut from Core 0.16.2: frame bytes, method IDs, Serde order,
budgets, malformed-input acceptance and retained retry/hash bytes are unchanged.
Consumers migrating from Core 0.15 or earlier still need the separate
[0.16 Account cut](0.16.md); this release adds no legacy reader or automatic migration.

The selected supplier cohort is Types 0.18.1, Runtime/macros/guard 0.19.1,
Platform facade 0.22 and Testkit 0.85. Testkit's native management adapter retains
facade 0.21. Core/Endpoint production graphs exclude both facades and Candid.
Rust 1.99.1 remains both minimum and pinned compiler. Native Build/Host 0.74.3
is retained. Supplier patches and sibling releases are outside this delivery.

[Macro ownership evidence](../../docs/evidence/endpoint-macro-owner.md)
preserves generated tokens and Wasm. The
[optional metadata change](../../docs/evidence/optional-metadata-derive.md)
removes Wire derive artifacts from codec-only builds, with a 413-byte opt-z
whole-fixture regression and unchanged opt-3 size. Later
[Types qualification](../../docs/evidence/README.md) retains
100,826 total / 86,886 code bytes at opt-z and 93,997 / 81,012 at opt-3;
partial instruction counters are unchanged. No build-time speedup is claimed.

Release delivery requires each group's admitted complete gate and registry-only
host/Wasm consumers after publication. Existing focused evidence is retained
separately from final release receipts and installed package verification.

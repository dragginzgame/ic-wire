# Core 0.16 release contract

Core/derive 0.16 selects canonical Platform Types 0.18 for optional host schemas.
Endpoint 0.6 adopts the new Core identity and Runtime/macros/exact guard 0.19.
Qualification uses facade/PocketIC 0.19 and Testkit 0.81; all suppliers are selected
from the registry without patches. Rust 1.99.1 stays minimum and pinned.

Account's Rust fields remain owner then optional [u8;32], but the owned Account
Serde implementation now treats that field as exact-length bytes. For an
anonymous owner, None stays `01 04 00`; explicit zero changes from
`01 04 01 + 32 zeros` to `01 04 01 20 + 32 zeros`. Generated browser fields are
Uint8Array. Principal's maximum is 29 bytes. Raw absent/zero representations,
logical equality/order/hash/text and external ledger Candid DTOs remain distinct.

Affected endpoints and clients must use fresh contract keys. Current production
macros retain `id` and exported-name defaults; changing schema or package version
does not change a default key. Old subaccount `[20, 00 × 31]` followed by blob
`[02, aa, bb]` can decode as subaccount `[00 × 31, 03]` and blob `[aa, bb]` under
an unchanged key. A fresh key refuses before payload work. Do not infer safety
from malformed-input checks. Resolve retained/in-flight operations under consumer
recovery rules and preserve original retry/signature/hash bytes. Inventory old
unframed Account Serde storage separately. There is no fallback or automatic migration.

[Published-supplier qualification](../../docs/evidence/account-platform-cut.md)
records exact Rust/TS bytes, malformed lengths, raw None/zero fields, all four
budget minima, host/Wasm/default-Core isolation, canonical identity and endpoint
admission/replies/borrowing/async/guards/rollback. Its 58-case Wire/Candid study
retains 1,230 operation pairs and both total/code uncompressed Wasm metrics;
small-input regressions and Candid drift remain visible. Do not sum separate
linked-guest savings or infer whole-application/native-time improvements.

The supplying [Platform #138](https://github.com/dragginzgame/ic-platform/issues/138)
shipped in Types 0.18; Runtime/facade 0.19 retain its canonical Principal identity.
The final Testkit 0.81 factory and release gates must pass on the selected source
before delivery. Registry-only installed consumers and archive/source/checksum
verification follow publication. Source preparation is not a publication receipt.

Automatic fingerprints and removal of manual macro IDs remain
[research](../../docs/evidence/contract-artifact.md), not part of this
release. They need stable canonical inputs/collision policy, recursive projection,
reusable consumer build ownership and diagnostic migration. One production
Serde/Postcard codec and the existing header layout remain selected.

The authorized delivery uses explicit `core` then `endpoint` release groups,
with their full gates. Publish derive before Core, then Endpoint. Keep qualification
packages unpublished, original evidence and tags intact, and sibling releases
outside this repository's delegated scope.
